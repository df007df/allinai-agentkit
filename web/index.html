Agent Client

连接 Hub，可靠执行本地 Agent 与受控能力，向上游回报状态。 本页就是内置 demo：授权你的 client 接入，实时看协议流动。

node bin/allinai-agent demo

# 终端 B：浏览器授权（会打开本站授权页）
node bin/allinai-agent login \

node bin/allinai-agent daemon

运作方式

  1. 01

    浏览器授权

    client 持有唯一 clientId，执行 login 后在授权页确认。 web 只在内存登记 token 到 clientId 的映射，重启即清空， 不发放任何全局令牌。

  2. 02

    连接与注册

    daemon 通过 WebSocket 长连 Hub，凭已授权 token 注册， 断线自动重连，注册与心跳在控制台实时可见。

  3. 03

    派发与回报

    从控制台派发 agent.run，client 在本地执行并持续上报事件， 全程走版本化的 v2 wire 协议。

使用场景

A

宿主服务：挂一个 Hub

把协议 Hub 挂进你现有的 HTTP 服务，鉴权与持久化全部由你实现， 包只负责协议编排。 

// 宿主侧：node:http + 你自己的 HubStore
import { createAgentHub } from "@allin-ai/agent-client/hub";

const hub = createAgentHub<MyUser>({
  authorize: (token) => loadUserByToken(token), // 你的鉴权
  store: myDurableStore(),                    // 你的持久化
});
hub.attach(httpServer);                       // WS 挂到 /api/agent-hub/v2/ws

// 向某个 client 派发一次执行
await hub.offer({
  principal: user,
  targetClientId: "agent-01",
  command: {
    kind: "agent.run",
    commandId: randomUUID(),
    executionId: randomUUID(),
    taskId: "task-1",
    attempt: 1,
    runtime: "codex",
    payload: { prompt: "修复登录页的空指针" },
  },
});
B

Agent 端：接入并执行任务

supervisor 负责连接、注册、断线重连与事件回报； 状态落 sqlite，执行交给可选的运行时适配。 

// client 侧：持久执行器
import {
  ClientStateStore, ClientSupervisor, WsClientTransport,
} from "@allin-ai/agent-client/client";
import { createRunnerManager } from "@allin-ai/agent-client/runtime";

const supervisor = new ClientSupervisor({
  store: new ClientStateStore(stateDbPath),
  transport: new WsClientTransport({
    hubBaseUrl: "https://hub.example",
    token: await loadToken(),          // login 授权后保存的 token
    clientId: "agent-01",
  }),
  runner: createRunnerManager(),       // Codex / Claude / Pi，可选
  maxConcurrentRuns: 1,
});

await supervisor.start();              // 连接、注册、收任务、上报事件
C

测试与本地联调：内存 Hub

单测里不需要数据库：内存 Hub 一行起步，协议行为与真实 Hub 完全一致。 

// 测试侧：易失内存实现，重启即清空
import { createMemoryHub } from "@allin-ai/agent-client/hub/testkit";

const hub = createMemoryHub({ token: "test-token" });
const server = http.createServer();
hub.attach(server);
server.listen(0, "127.0.0.1");

// 断言你的宿主逻辑：注册、offer、事件上报
assert.equal(hub.listClients().length, 0);

E

在自己的网站上替换内存 Hub

demo 站默认用易失内存 Store。生产上实现你自己的 HubStore 接口（六个方法），把持久化换成数据库， 协议层不用动一行。 

// 1) 实现你自己的持久化 Store（以 Postgres 为例，六个方法）
import {
  createAgentHub, type HubStore,
} from "@allin-ai/agent-client/hub";

class PostgresHubStore implements HubStore<MyUser> {
  async registerClient(input) {
    // 幂等：同 principal+clientId 返回稳定 connectionKey；
    // 归属冲突（同 clientId 不同 principal）必须拒绝
  }
  async heartbeat(input)     { /* UPDATE clients SET last_seen = now() */ }
  async listPendingOffers(input) {
    /* 只返回该 principal 拥有、未确认的 offer，按持久投递顺序 */
  }
  async enqueueOffer(input)  {
    /* 先落库再返回；按命令身份去重，connectionKey 与注册一致 */
  }
  async ingestEvents(input)  {
    /* (executionId, eventSeq) 去重落库；只回报已持久化的连续
       水位；收到即退役 run offer，done/failed 等终态取消 offer */
  }
  async acknowledgePluginSync(input) { /* 记录插件确认水位 */ }
}

// 2a) 挂到你自己的站点
const hub = createAgentHub({
  authorize: myAuthorizer,
  store: new PostgresHubStore(),
});

// 2b) 或者：让 demo 站本身跑在你的 Store 上（观测与授权页都保留）
import { startDemoSite } from "@allin-ai/agent-client/demo";
const site = await startDemoSite({ port: 4317, store: new PostgresHubStore() });

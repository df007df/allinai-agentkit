运作方式 模块导出 控制台

独立持久的
Agent Client

连接 Hub，可靠执行本地 Agent 与受控能力，向上游回报状态。 本页就是内置 demo：授权你的 client 接入，实时看协议流动。

接入你的 Agent 查看模块导出
quickstart.sh 
# 终端 A：启动官网与 demo hub
node bin/allinai-agent demo

# 终端 B：浏览器授权（会打开本站授权页）
node bin/allinai-agent login \
  --hub http://127.0.0.1:4317

# 终端 B：常驻接入，然后回到本页控制台
node bin/allinai-agent daemon

运作方式

  1. 01

    浏览器授权

    client 持有唯一 clientId，执行 login 后在授权页确认。 web 只在内存登记 token 到 clientId 的映射，重启即清空， 不发放任何全局令牌。

  2. 02

    连接与注册

    daemon 通过 WebSocket 长连 Hub，凭已授权 token 注册， 断线自动重连，注册与心跳在控制台实时可见。

  3. 03

    派发与回报

    从控制台派发 agent.run，client 在本地执行并持续上报事件， 全程走版本化的 v2 wire 协议。

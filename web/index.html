allinai-agentkit

独立持久 Agent Client：连接 Hub，可靠执行本地平台 Agent 与受策略门控的能力，并向上游回报状态。

它是什么

一个 npm 包 @allin-ai/agent-client + CLI allinai-agent：协议层（versioned wire schema）、通用 Node Hub（HubStore 端口）、可重连执行 client、运行时适配（Codex / Claude / Pi，均为可选 peer）与插件能力。

快速开始

  1. 终端 A：node bin/allinai-agent demo 启动官网与 demo Hub
  2. 终端 B：allinai-agent login --hub http://127.0.0.1:4317 浏览器授权
  3. 终端 B：allinai-agent daemon 常驻接入
  4. 回到本页控制台派发任务、观察协议事件流

无浏览器环境：demo 启动时终端会打印 bootstrap token，可用 init --hub <url> --token <token> 代替 login。

导出一览

  • /protocol 协议 · /hub Node Hub · /hub/testkit 内存实现
  • /client 执行 client · /runtime 运行时适配 · /plugins 插件
  • /demo 本页 demo 服务 · /cli 命令入口

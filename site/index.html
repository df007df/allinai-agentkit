独立持久的
Agent Client

连接 Hub，可靠执行本地 Agent 与受控能力，向上游回报状态。 npm 包 @allin-ai/agentkit 已发布，npx 一条命令在本地拉起 demo 控制台：授权你的 client 接入，实时看协议流动。

GitHub 仓库 模块与架构
quickstart.sh 
# 终端 A：npx 拉起本地 demo 控制台与 hub（Node.js ≥ 22.18）
npx @allin-ai/agentkit demo

# 终端 B：浏览器授权（会打开授权页）
npx @allin-ai/agentkit login \
  --hub http://127.0.0.1:4317

# 终端 B：常驻接入，然后回到控制台页面
npx @allin-ai/agentkit daemon

运作方式

  1. 01

    浏览器授权

    client 持有唯一 clientId，执行 login 后在授权页确认。 web 只在内存登记 token 到 clientId 的映射，重启即清空， 不发放任何全局令牌。

  2. 02

    连接与注册

    daemon 通过 WebSocket 长连 Hub，凭已授权 token 注册， 断线自动重连，注册与心跳在本地 demo 控制台实时可见。

  3. 03

    派发与回报

    从控制台派发 agent.run，client 在本地执行并持续上报事件， 全程走版本化的 v2 wire 协议。

使用场景

A

宿主服务：挂一个 Hub

鉴权与持久化全部由你实现，包只负责协议编排，一条 offer 派发执行。

 B

Agent 端：接入并执行任务

supervisor 负责连接、注册、重连与事件回报；状态落 sqlite，执行交给可选运行时。

 C

测试与本地联调：内存 Hub

单测不需要数据库：内存 Hub 一行起步，协议行为与真实 Hub 完全一致。

 D

一键 demo 控制台

本地调试利器：内存 Hub、浏览器授权与控制台一条命令起，仅监听回环地址。

 E

在 Next.js 集成内存 Hub

custom server 挂 Hub，Server Component 直接读 Store 列出 client 与在线状态。

 F

在 Next.js 实现自己的 HubStore

生产持久化：六个方法换成你的数据库，挂法与内存版完全一致。

完整代码示例、CLI 参考与集成细节见文档。
